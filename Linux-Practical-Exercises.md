# Linux Practical Exercises
Hands-on Linux practice completed as part of my transition into IT Support and Cybersecurity.

---
## Exercise 1: Navigation Basics
**Commands used:** `pwd`, `ls`, `ls -la`, `cd`

**What I practised:**
- Checking current directory location
- Listing files and folders (including hidden files)
- Moving between directories
  
---
## Exercise 2: Create and Organise Files
**Commands used:** `mkdir`, `touch`, `ls -l`, `mv`, `cp`

**What I practised:**
- Creating folders and files
- Renaming files
- Copying files
- Organising work inside a practice directory
  
---
## Exercise 3: Permissions Practice
**Commands used:** `ls -l`, `chmod 600`, `chmod 644`, symbolic `chmod` (`u=rw`, `go-rwx`, etc.)

**What I practised:**
- Understanding file permissions (`rwx`)
- Changing permissions using numeric mode
- Changing permissions using symbolic mode
- Making a file private vs readable by others

---
## Exercise 4: Ownership Check
**Commands used:** `ls -l`, `whoami`

**What I practised:**
- Identifying the owner of files
- Confirming the current logged-in user
  
---
## Exercise 5: Finding Files
**Commands used:** `find`

**What I practised:**
- Searching for files by name
- Locating `.txt` files and specific filenames within directories
  
---
## Exercise 6: Searching Inside Files
**Commands used:** `echo`, `cat`, `grep`, `grep -i`

**What I practised:**
- Writing content into files
- Viewing file content
- Searching for specific words inside files
- Case-insensitive searching
  
---
## Exercise 7: Process Management
**Commands used:** `ps aux`, `ps aux | grep`, `top`

**What I practised:**
- Viewing running processes
- Filtering processes by name
- Monitoring live system activity with `top`
  
---
## Exercise 8: System Resource Check
**Commands used:** `df -h`, `top`, `uname -a`

**What I practised:**
- Checking disk space usage
- Identifying system information
- Monitoring resource usage
  
---
## Exercise 9: Real-time Log Monitoring
**Commands used:** `echo`, `cat`, `tail -f`, `>>`

**What I practised:**
- Creating and updating a log-style file
- Watching a file in real time
- Understanding the difference between `>` (overwrite) and `>>` (append)
  
---
## Exercise 10: Mini Troubleshooting Scenario
**Commands used:** `mkdir -p`, `echo`, `chmod 000`, `find`, `ls -l`, `chmod 644`, `cat`

**What I practised:**
- Creating nested folders
- Removing all permissions from a file
- Finding a file by name
- Diagnosing permission issues
- Restoring access and reading the file content
  
This exercise simulated a real IT Support scenario where a user cannot access a file due to permission problems.
